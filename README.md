# 拾错 ShiCuo

把做错的题，变成下一次的底气。

这是「拾错」的 GitHub Pages 静态展示版：首页、公开错题广场、搜索筛选、错题详情与数据库设计说明。完整 Next.js + Supabase 服务端版本保留在本地项目中。

- 在线展示：https://xiaojinyi1.github.io/shicuo/
- 静态站源码：`index.html`（单文件、无外部依赖）
- 数据均为 Demo 样例；登录、写入、管理后台需在完整 Next.js 版本运行。

## 本地预览

直接打开 `index.html`，或在目录中启动任意静态服务器。

## 说明

GitHub Pages 只能托管静态文件，无法运行 Next.js SSR、middleware、Server Actions 或 Supabase 会话。完整应用请部署到 Vercel 等 Node 托管平台。
